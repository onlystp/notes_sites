Rails 中 **Time** 與 **Date** 可以用來處理日期與時間，甚至還有時區的功能。時間操作很直覺，像是在讀英文。

---

# 取得當前時間

在 Rails 中，應優先使用 **`Time.zone`** 系列，因為它會自動處理你在 `application.rb` 設定的時區（例如台北 `+0800`）。

| **功能**            | **指令**                             | **說明**                 |
| ----------------- | ---------------------------------- | ---------------------- |
| **當下時間 (含時區)**    | `Time.zone.now`                    | **最推薦寫法**，包含日期、時間與時區。  |
| **今天 (不含時間)**     | `Date.current`                     | 回傳當下時區的「今天」。           |
| **昨天 / 明天**       | `Date.yesterday` / `Date.tomorrow` | 取得相對日期。                |
| **原生 Ruby (不推薦)** | `Time.now`                         | 取得系統（伺服器）本地時間，易造成時區錯誤。 |
|                   |                                    |                        |

---

# 時間計算

直接對數字呼叫時間單位：

|**範例**|**結果 (相對於現在)**|
|---|---|
|`5.days.ago`|5 天前的這個時間。|
|`1.month.from_now`|1 個月後的這個時間。|
|`2.weeks.since(Time.zone.now)`|從某個時間點算起 2 週後。|
|`3.hours.ago`|3 小時前。|

---

# Begin & End

取得某個時間點的「開端」或「結束」：

|**指令**|**說明**|**範例結果**|
|---|---|---|
|**當天開端**|`.beginning_of_day`|`2026-02-05 00:00:00`|
|**當天結束**|`.end_of_day`|`2026-02-05 23:59:59`|
|**本週一**|`.beginning_of_week`|該週的週一凌晨。|
|**本月底**|`.end_of_month`|該月最後一秒。|
|**當季結束**|`.end_of_quarter`|該季最後一秒。|
|**取得特定時間**|`.change(hour: 9)`|把時間強制改為早上 9 點。|

---

# Formatting

時間印出來給使用者看：

```rb
time = Time.zone.now
time.to_fs(:db)      # "2026-02-05 09:51:00" (適合存入資料庫的字串)
time.to_fs(:short)   # "05 Feb 09:51"
time.strftime("%Y/%m/%d %H:%M") # 自定義：2026/02/05 09:51
```


---

# 判斷

|**指令**|**說明**|
|---|---|
|`time.past?`|是否為過去時間？|
|`time.future?`|是否為未來時間？|
|`time.today?`|是否為今天？|
|`time.on_weekday?`|是否為工作日（週一至週五）？|
|`time.on_weekend?`|是否為週末？|

# Time Helpers

在寫 **TDD** 時，如果你要測試「如果現在是月底，請假邏輯會怎樣」，你可以「暫停」或「移動」時間：

```rb
# 在測試中使用
travel_to Time.zone.local(2026, 12, 31, 23, 59) do
  # 這裡面的 Time.zone.now 會永遠回傳 2026 年底
  expect(Date.current).to eq(Date.new(2026, 12, 31))
end
```
